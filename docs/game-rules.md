# M-OS Game Rules

> Правила игры для участников. Будет дополняться перед мероприятием.

## Основная идея

M-OS — дополнительный игровой слой поверх праздника. Игра **необязательна** — главное общение и праздник.

## Роли

- **Игрок** — участник дня рождения
- **Администратор** — организатор игры

## Игровые механики

### М-коины

Внутренняя валюта. Используется для обменов и будущего аукциона.

### QR-коды

Размещены на территории дачи. Сканирование даёт награды.

Политики сканирования:

- **FIRST_PLAYER** — награда только первому
- **EVERY_PLAYER** — каждый может отсканировать один раз
- **LIMITED** — ограниченное число сканов

### Предметы

Коллекционные объекты с редкостью. Некоторые уникальны (`isUnique`).

### Числовая коллекция

Собрать полный набор номеров.

### Задания

Автоматические и административные.

### Обмены

Игроки создают сделки: предметы + М-коины.

### Очки

Категории: TOTAL, EXPLORER, COLLECTOR, TRADER, QUEST.

### Условия победы

Настраиваются admin для каждой сессии.

## Карта

- Изображение карты дачи
- Координаты точек в процентах (0–100)
- Туман войны: скрытые точки открываются при исследовании

## Секреты

Персональные коды от admin — стартовые награды, задания, подсказки.
